모바일웹 열기

1 스마트폰 바탕화면 앱(PWA) 추가 & 4자리 PIN 로그인

바탕화면에 앱(바로가기) 1초 설치

기사님이 매번 긴 인터넷 주소를 입력할 필요 없이 일반 스마트폰 어플처럼 트럭 아이콘 앱으로 실행할 수 있습니다.

  1. 스마트폰 브라우저로 모바일 웹 접속
  2. 상단 노란색 [바로가기] 버튼 터치
  3. 안드로이드: [홈 화면에 추가] / 아이폰: 사파리 공유창 ➔ [홈 화면에 추가]
  4. 바탕화면에 "현대렌탈배송" 앱이 설치되어 1터치로 즉시 열립니다.

숫자 4자리 PIN 로그인

복잡한 영문 비밀번호 대신 현장에서 빠르고 편하게 숫자 4자리로 인증합니다.

  • 이름: 본인 성명 입력 (예: 김승지, 조경찬)
  • 비밀번호: 숫자 4자리 (초기 공통 비밀번호: 1234)
  • [자동 로그인] 체크: 다음 접속 시 로그인 창을 건너뛰고 오늘 배송 건이 바로 뜹니다.

📱 실제 모바일 로그인 화면

• 성명과 4자리 비밀번호(1234)를 입력하고 [자동 로그인]에 체크해두면 하루 종일 재로그인 없이 즉시 배송 화면으로 진입합니다.

• 비밀번호 변경이 필요할 경우 관제 PC 대시보드 우측 상단 메뉴의 [사용자 설정]에서 변경 가능합니다.

2 ★ 기사 하루 업무 전체 프로세스 & 1분 운행마감 (필독)

★ 현장 필수 준수 사항

배송기사의 출근부터 배송 완료, 센터 복귀 및 퇴근 마감까지의 실제 5단계 업무 순서입니다.

① 출근 및 법인차량 선택 (시작 계기판 확인) 오전 08:30

모바일웹 상단 [차량선택]을 누른 뒤 오늘 탑승할 스타리아(예: 801부8744)를 선택합니다. 차량을 선택하면 이전 운행자(1팀 또는 기사)가 마감한 최종 계기판 Km가 내 시작 계기판으로 자동 연동됩니다.

💡 차량을 잘못 선택했거나 배차를 취소할 때: [차량선택] 팝업에서 현재 선택된 초록색 체크 카드를 한 번 더 터치하면 선택이 취소되어 '미배차 대기' 상태로 돌아갑니다.
② 배송 목록 순서 확인 & 도로 동선 파악 출발 전

오늘 나에게 배정된 배송지 목록을 확인합니다. 상단의 [🗺️ 전체 배송 지도 보기 & 실제 주행 경로] 버튼을 누르면 오늘 방문할 전체 경유지와 추천 도로 주행선을 지도에서 한눈에 볼 수 있습니다.

• 고객의 긴급 요청이나 교통 상황에 따라 각 카드의 [▲] / [▼] 버튼을 눌러 방문 순서를 즉시 바꿀 수 있으며, 변경 즉시 관제 PC 화면에도 동기화됩니다.

③ 배송지 출발: [티맵 안내] 원클릭 실행 (필수!) ★ 기사 필수 준수

배송지로 출발할 때는 스마트폰 티맵 앱을 따로 켜지 마시고, 반드시 모바일웹의 로즈레드 색상 [티맵 안내] 버튼을 터치하여 출발하십시오!

  • 버튼 터치 즉시: 관제 대시보드와 시간 관리 시스템에 기사님의 출발 시각이 초 단위로 자동 전송됩니다.
  • 내비게이션 자동 실행: 고객사의 도로명 주소가 티맵 내비게이션 목적지로 자동 입력되어 즉시 길안내가 시작됩니다.
④ 배송지 도착 완료 처리 & 사진/메모 기록 현장 도착

고객사 현장에 도착하면 즉시 [배송지 도착] 버튼을 누릅니다.

  • 소요 시간 자동 산출: 출발 시각부터 도착 시각까지의 주행 소요시간(예: 35분 소요)이 시스템에 기록됩니다.
  • 현장 사진 첨부: 부재중 문 앞 보관 사진이나 설치 완료 사진은 [📷 사진 첨부]로 등록 시 데이터 절약을 위해 자동 압축되어 클라우드에 영구 저장됩니다.
  • 고객 통화: 초록색 전화기 버튼을 누르면 오발신 방지 확인 후 스마트폰 통화 화면으로 바로 연결됩니다.
⑤ 센터 복귀 후 [운행마감] (단 1분 소요!) 하루 일과 종료

모든 배송을 마치고 가산 센터로 복귀하면 상단 운행차량 카드 우측의 [운행마감] (초록색 깃발) 버튼을 누릅니다.

1. 종료 계기판 입력

차량 계기판에 표시된 현재 최종 Km 숫자만 입력 (당일 실주행거리 자동 계산)

2. 주차비/주유비 (선택)

오늘 지출한 영수증 금액과 특이사항 메모 입력

3. [저장 및 마감] 클릭

법인차량 운행일지로 일괄 전송되며 오늘 배송 완료!

* 만약 센터로 복귀하지 않고 현지(자택)로 바로 퇴근할 경우, 마감 팝업의 [도착지 변경]을 눌러 자택 주소로 설정 후 마감하시면 됩니다.

3 법인차량 선택 및 재터치 취소(토글) 상세

배송기사가 당일 운행할 스타리아 차량을 지정하거나 취소하는 방법입니다.

차량 선택

상단 [차량선택] 클릭 ➔ 본인 차량 카드 클릭 ➔ 시작 계기판 자동 로드 및 실시간 운행차량으로 등록됨.

선택 취소 (토글)

차량을 잘못 선택했거나 미배차 상태로 돌릴 때, 이미 체크된 카드를 한 번 더 터치하면 배차가 즉시 해제됩니다.

사무실 관제팀 & 총괄 관리자용

PC 통합 관제 대시보드 실무 프로세스 (`index.html`)

배송지 엑셀/CSV 일괄 등록부터 기사 배정, 퀵/방문수령 분기, 최적 도로 경로 계산, 실시간 관제까지 순서별 완벽 안내

대시보드 열기

PC 관제 대시보드 화면 구성 및 핵심 메뉴 번호 안내

1 날짜 선택 캘린더

상단 캘린더 피커로 당일 및 과거/미래 배송 스케줄을 날짜별로 즉시 전환합니다.

2 [CSV 등록] 버튼

ERP 배송 엑셀 CSV 파일을 원클릭으로 일괄 업로드합니다. (시간 보존 병합 탑재)

3 [+ 직접 추가] 버튼

당일 낮에 급히 접수된 긴급 건이나 수기 주문을 즉시 추가 등록합니다.

4 [배정 알림] 버튼

배정 완료된 배송 일정을 기사님들의 카카오톡/문자 메시지로 일괄 발송합니다.

5 [이력 조회] 버튼

고객 계약번호별 과거 배송/회수 내역 및 현장 기사 메모를 신속 검색합니다.

6 우측 상단 팝업 메뉴

📖 시스템 매뉴얼, 배송 스케줄 시간 관리, 법인차량 운행일지, 관리자 설정 진입.

관리자 당일 배송관제 6단계 업무 진행 순서

1 아침 배송 스케줄 CSV 등록 & '시간 보존 병합' 오전 08:00

ERP에서 내려받은 당일 배송 CSV 파일을 상단 [CSV 등록] 버튼을 통해 업로드합니다.

🛡️ 시간 보존 병합 엔진 탑재: 낮에 추가 건이나 주문 변경으로 인해 CSV를 다시 덮어씌우더라도, 기사님이 현장에서 이미 찍은 출발 시각, 도착 시각, 현장 사진, 메모는 절대로 삭제되지 않고 100% 안전하게 유지됩니다.
2 기사별 배정 & 담당 거점(출발지) 확인 배정 단계

메인 테이블에서 각 주문의 담당기사 드롭다운을 선택하여 배송기사별로 배정합니다.

• 기사별로 자택 또는 개별 거점에서 출발하는 경우, 우측 상단 메뉴의 [기사별 출발지/거점 관리]에서 기사별 출발지 주소를 설정해두면 해당 거점 기준으로 경로가 계산됩니다.

3 배송 방식 분기 관제: [⚡ 퀵 배송] 및 [🏢 방문수령] 처리 관리자 전용 기능

모든 주문이 기사 차량 직배송이 아니므로, 주문 유형에 맞춰 관리자가 정확하게 처리해야 합니다.

⚡ 퀵 배송 처리 요령 외주 퀵서비스

1. 오토바이 퀵 접수 완료 시: 메인 테이블의 [접수완료] 버튼 클릭 ➔ 퀵 접수 시각 자동 기록.
2. 퀵 기사가 물품 픽업 후 출발 시: [퀵 출발] 버튼 클릭 ➔ 퀵 출발 시각 및 접수 후 경과시간 기록.
* 국세청 세무 무결성을 위해 법인차량 운행일지에서 자동 제외됩니다.

🏢 방문수령 처리 요령 고객 내방

1. 길안내 불필요: 고객이 센터로 직접 찾아오는 주문이므로 티맵 버튼이 완전 제거되어 있습니다.
2. 고객 방문 인도 시: 초록색 [수령 완료] 버튼 클릭 ➔ 수령 완료 시각이 기록되며 완료 처리됩니다.

4 카카오 도로 경로 계산 & 드래그앤드롭 순서 최적화 경로 최적화

지도 상단의 [🔄 실제 도로 경로 계산] 버튼을 누르면 실시간 교통상황이 반영된 실제 주행 도로선(파란색)과 총 주행거리(km), 예상 시간이 계산됩니다.

• 테이블 행을 마우스로 끌어다 놓거나(드래그앤드롭) [▲]/[▼] 버튼을 누르면 순서가 바뀌며, 기사님의 스마트폰 화면에도 1초 만에 순서가 동기화됩니다.

5 기사 배정 알림 전송 (카카오톡/SMS) 알림 발송

순서 정렬이 끝나면 상단의 [배정 알림] 버튼을 눌러 각 기사님들에게 오늘 방문할 업체 목록과 모바일웹 바로가기 링크를 카카오톡 알림톡/문자로 일괄 전송합니다.

6 실시간 관제 & 시간 관리 타임트래커 모니터링 실시간 관제

기사님들이 배송을 수행하면서 누르는 티맵 출발 시각, 도착 완료 시각, 현장 사진이 대시보드 메인 테이블과 모바일 관리자 카드에 실시간 갱신됩니다.

• 상단 우측 메뉴 ➔ [배송 스케줄 시간 관리]를 열면 기사별 상세 출발/도착 타임라인 및 이동 소요 시간을 한눈에 대조 분석할 수 있습니다.

국세청 법정 서식 호환 & 세무 증빙

법인차량 운행일지 시스템 & 1·2팀 차량 공유 (`vehicle_log_tracker.html`)

일반 직배송 연동 원리, 1·2팀 차량 공유 프로토콜, 국세청 표준 CSV 다운로드 총괄

차량 일지 열기

1. 일반 직배송과 법인차량 운행일지의 자동 연동 원리

현대렌탈의 '일반 직배송'은 배송기사가 회사 법인차량(스타리아 등)을 직접 운전하여 고객사에 물품을 전달하는 업무입니다.

• 실시간 경유지 자동 기록: 기사가 모바일웹에서 직배송 건의 [티맵 안내]와 [도착 완료]를 누르면, 해당 고객사의 도로명 주소와 도착 시각이 당일 법인차량의 공식 경유지 목록으로 자동 저장됩니다.

• 운행마감 시 계기판 확정: 센터 복귀 후 기사가 모바일에서 [운행마감]을 누르면, 당일 주행한 모든 직배송 경유지와 최종 계기판 Km가 결합되어 국세청 업무용 승용차 운행기록부로 자동 완성됩니다.

2. 1팀 / 2팀 법인차량 공유 3대 골든 룰 & 운영 프로토콜

필독 운영 수칙

1팀과 2팀은 차량(스타리아)을 함께 공유합니다. 계기판 누락과 오차를 방지하기 위해 다음 3대 수칙을 철저히 준수합니다.

1

인계 시 [운행마감] 필수

오전 운행자(2팀 기사)는 센터 복귀 즉시 모바일에서 [운행마감]을 눌러 최종 계기판 숫자를 확정 저장합니다.

2

인수 시 계기판 대조

다음 탑승자(1팀 또는 오후 기사)는 차량 계기판의 실제 숫자와 화면의 시작 계기판 숫자가 일치하는지 확인 후 출발합니다.

1팀 운행은 '기타' 표기

1팀 직원이 외부 업무로 차량을 운행한 경우 운전자를 `기타`로 지정하고 성명을 직접 입력하여 팀별 사용 내역을 구분합니다.

📌 실제 차량 공유 운영 시나리오:

• 오전 (2팀 배송): 시작 50,000 km ➔ 배송 후 50,060 km (기사 모바일웹에서 [운행마감] 처리)

• 오후 (1팀 업무): 1팀 직원이 50,060 km로 인수 ➔ 50,110 km 운행 후 [운행일지 직접 등록] (운전자: 기타 / 시작 50,060 / 종료 50,110)

• 익일 아침: 2팀 기사 출근 시 모바일 시작 계기판이 50,110 km로 자동 승계되어 오차가 0km로 유지됩니다.

3. 운행일지 시스템 화면 기능 & 운전자 직접입력 가이드

운전자 명단 및 명단 외 인원 '기타 직접입력' 규칙

• 등록 운전자: 강동우, 김승지, 조경찬, 이성호, 장종순, 박종환, 한민혁

• 명단에 없는 인원 및 1팀 담당자: 운전자 선택에서 `기타`를 선택한 후, 실제 운전자 성명을 직접 입력하여 저장합니다.
