배송기사 스마트폰 모바일웹 (`mobile.html`)

스마트폰 하나로 티맵 길안내, 순서변경, 실시간 출발/도착 및 운행마감까지 원스톱 처리

모바일웹 바로 실행

1 스마트폰 바탕화면 앱(PWA) 추가 & PIN 로그인

바탕화면에 앱(바로가기) 1초 설치

기사님이 매번 긴 인터넷 주소를 입력할 필요 없이 일반 스마트폰 어플처럼 트럭 아이콘 앱으로 실행할 수 있습니다.

  1. 스마트폰 브라우저로 모바일 웹 접속
  2. 상단 노란색 [바로가기] 버튼 터치
  3. 안드로이드: [홈 화면에 추가] / 아이폰: 사파리 공유창 ➔ [홈 화면에 추가]
  4. 바탕화면에 "현대렌탈배송" 앱이 설치되어 1터치로 즉시 열립니다.

숫자 4자리 PIN 로그인

복잡한 영문 비밀번호 대신 현장에서 빠르고 편하게 숫자 4자리로 인증합니다.

  • 이름: 본인 성명 입력 (예: 김승지, 조경찬)
  • 비밀번호: 숫자 4자리 (초기 공통 비밀번호: 1234)
  • [자동 로그인] 체크: 다음 접속 시 로그인 창을 건너뛰고 오늘 배송 건이 바로 뜹니다.

2 법인차량 선택 및 재터치 취소(토글) 기능

오전 출발 전 탑승할 법인차량을 지정합니다. 차량을 잘못 선택했거나 배송 중 차량을 인계할 때 언제든 해제할 수 있습니다.

차량 선택

1. 차량 카드 터치

상단 [차량선택] 버튼 터치 후 탑승할 스타리아(예: 801부8744)를 누르면 시작 계기판이 자동 로드됩니다.

선택 취소 (토글)

2. 한 번 더 눌러 취소

이미 체크된 차량을 한 번 더 터치하면 차량 선택이 즉시 해제되어 '미배차 대기'로 복귀합니다.

계기판 자동 승계

3. 누적 Km 자동 연동

이전 운행자(1팀 또는 다른 기사)가 마감한 최종 계기판 Km가 내 시작 계기판으로 오차 없이 승계됩니다.

3 배송 유형별 버튼 조작법 (직배송 / 퀵배송 / 방문수령)

★ 기사 필독 사항

모바일웹은 배송 주문의 성격에 따라 필요한 버튼만 자동으로 표출됩니다. 잘못 누르는 실수를 시스템이 원천 차단합니다.

배송 유형 좌측 버튼 (출발/접수) 우측 버튼 (도착/출발) 실무 요령 및 동작 안내
🚚 일반 직배송
기사 직접 차량 운행
 • 출발 전: [티맵 안내]를 누르면 관제에 출발시각이 기록되고 스마트폰 티맵 앱이 자동 실행됩니다.
• 도착 후: [도착 완료]를 누르면 도착시각과 주행 소요시간(분)이 자동 기록됩니다.
⚡ 퀵 배송
오토바이/다마스 외주
 • 퀵 접수 시: [접수완료] 클릭 ➔ 관리자 대시보드에 퀵 접수 상태 즉시 공유.
• 퀵 기사 픽업 시: [퀵 출발] 클릭 ➔ 물품 출발 상태 기록.
* 차량 운행이 아니므로 법인차량 운행일지에서 자동 제외되어 세무 증빙이 보호됩니다.
🏢 방문수령
고객이 센터로 내방
 • 티맵 버튼 완전 삭제: 고객이 오는 건이므로 내비 버튼을 숨겨 실수 터치를 방지합니다.
• 고객 인도 시: 초록색 [수령 완료 처리] 버튼만 한 번 누르면 끝납니다.

4 센터 복귀 후 1분 운행마감 프로세스

모든 배송을 마치고 센터(또는 자택)로 복귀하면 상단 [운행마감] 버튼으로 오늘 운행일지를 전산 마감합니다.

STEP 1
[운행마감] 터치

모바일웹 상단 우측 초록색 깃발 아이콘 버튼 터치

STEP 2
종료 계기판 입력

차량 계기판의 현재 최종 Km 숫자만 입력 (실주행거리 자동 계산)

STEP 3
주차비/주유비 (선택)

당일 지출한 영수증 금액과 특이사항 메모 입력

STEP 4
[저장 및 마감] 완료

법인차량 운행일지 시스템으로 자동 전송 완료!

엑셀/CSV 2중 다운로드 기능

상단 [CSV 다운로드] 버튼을 누르면 용도에 맞게 2가지 서식으로 즉시 내려받을 수 있습니다.

1. 배송지별 상세 CSV (추천)

모든 경유지명, 도로명 주소, 도착 시간, 구간별 계기판 Km, 영수증 주차비/주유비까지 모두 포함되어 내부 감사 및 비용 정산에 완벽합니다.

2. 일자별 요약 CSV (국세청 표준)

국세청 법인세 신고용 표준 서식 호환본으로 세무사 및 국세청 홈택스 제출에 최적화되어 있습니다.

필독 운영 수칙

1팀 / 2팀 법인차량 공유 3대 골든 룰

차량은 공유하되 계기판 충돌과 누락을 방지하는 실무 프로토콜

1

인계 시 [운행마감] 필수

오전 운행자(2팀 배송기사)는 센터 복귀 즉시 모바일에서 [운행마감]을 눌러 최종 계기판 숫자를 저장합니다.

2

인수 시 계기판 대조

다음 탑승자(1팀 또는 오후 기사)는 차량 계기판의 실제 숫자와 화면의 시작 계기판 숫자가 맞는지 확인 후 출발합니다.

3

1팀 운행은 '기타' 표기

1팀 직원이 외부 업무로 차량을 운행한 경우 운전자 명단을 `기타`로 기재하여 팀별 사용 내역을 구분합니다.

자주 묻는 질문 TOP 6 (FAQ)

Q1. 낮에 추가 건이 생겨 관리자가 CSV를 다시 올렸는데, 이미 찍은 출발/도착 시간이 사라지나요?

A. 절대 사라지지 않습니다. 시스템에 구축된 시간 보존 병합 엔진에 의해 기사님이 기록한 시각, 사진, 메모는 100% 영구 유지됩니다.

Q2. 퀵 배송 건을 처리했는데 왜 법인차량 운행일지 경유지 목록에 안 나오나요?

A. 정상입니다. 퀵 배송은 법인차량을 운행한 것이 아니므로 국세청 세무 증빙의 무결성을 위해 시스템이 자동으로 운행일지 집계에서 제외합니다.

Q3. 모바일웹에서 차량을 잘못 선택했는데 취소가 안 되나요?

A. 취소 가능합니다. 상단 [차량선택]을 누른 후, 현재 선택된 초록색 체크 카드를 한 번 더 터치하면 즉시 선택이 해제되어 미배차 상태로 복귀합니다.

Q4. 센터로 복귀하지 않고 자택으로 바로 퇴근(현지 퇴근)할 때는 어떻게 마감하나요?

A. 모바일 [운행마감] 팝업에서 도착지 우측의 [도착지 변경]을 눌러 '자택' 주소를 입력하고 마감하시면 해당 위치까지의 거리로 정상 마감됩니다.

Q5. 기사 모바일웹 화면에서 글씨나 버튼이 너무 작게 보입니다.

A. 스마트폰 브라우저 설정에서 텍스트 크기를 100% 기본값으로 맞춰주시고, 상단 [바로가기]를 통해 홈 화면에 앱으로 추가하여 실행하시면 전체화면으로 가장 시원하게 이용하실 수 있습니다.

Q6. 본 매뉴얼을 종이 인쇄나 PDF 파일로 보관할 수 있나요?

A. 네 가능합니다. 화면 우측 상단의 [PDF / 인쇄 다운로드] 버튼을 누르면 불필요한 버튼들이 숨겨지고 A4 출력용 깔끔한 문서로 자동 변환되어 PDF 저장이 가능합니다.
