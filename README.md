# 배송 스케줄 및 실시간 관제 시스템 (Hyundai Rental Delivery Management)

차량 내비게이션 최적 주행 동선 및 배송 현황 관제 서비스입니다.

## 주요 기능
- 🚚 실시간 배송 및 회수 현황 관제
- 🗺️ 차량 내비게이션 및 최적 주행 동선(Leaflet/카카오맵/Tmap) 시각화
- 📋 방문 순서 재정렬 및 물목 관리
- ☁️ 클라우드 데이터베이스(Supabase) 및 Vercel 배포 기반 웹 서비스

## 기술 스택
- **프론트엔드**: HTML5, CSS3, JavaScript, Leaflet
- **데이터베이스**: Supabase (PostgreSQL)
- **호스팅 및 배포**: Vercel
- **버전 관리**: GitHub
