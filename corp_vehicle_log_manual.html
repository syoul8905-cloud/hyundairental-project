Chapter 1

솔루션 핵심 특장점 (5대 차별화 포인트)

1. 무설치·무로그인 독립형 SPA

별도의 서버나 데이터베이스 계정 없이 URL 링크만 전달하면 상대방 브라우저에서 즉시 실행되며, 모든 데이터는 안전하게 로컬(`LocalStorage`)에 자동 보관됩니다.

2. Daum 도로명 주소 1초 완성

카카오/Daum 우편번호 서비스가 임베드되어 있어 [🔍 주소 검색] 버튼 하나로 건물명이나 주소 검색 시 도로명 주소가 오타 없이 자동 완성됩니다.

3. 월말 계기판 Km 스마트 자동분배

매일 계기판을 적지 못했더라도 월말 최종 계기판 숫자만 입력하면, 당월 전체 경유지에 맞추어 계기판 역전 0%, 오차 0km로 마일리지를 자동 비례 분배합니다.

4. 국세청 & 실무 12열 듀얼 CSV

국세청 법정 요약 서식은 물론, 회계/감사 제출용 실무 표준 12열(방문지별 주차비/주유비 포함) 엑셀을 UTF-8 BOM 인코딩으로 한글 깨짐 없이 즉시 다운로드합니다.

5. 1클릭 샘플 & 고객사 브랜딩

시연 시 [🎯 1클릭 샘플 데이터 로드] 버튼으로 1달 치 70여 개 방문지 데이터를 1초 만에 채우고, 상단 타이틀 클릭으로 대상 기업명으로 즉시 변경 가능합니다.

6. 완벽한 JSON 백업 및 복구

전체 등록 차량과 수개월 치 운행기록 데이터를 JSON 백업 파일로 저장하고 언제든 다른 PC나 브라우저로 100% 원복하여 시연을 이어갈 수 있습니다.

Chapter 2

B2B 데모 시연 3초 퀵스타트 (현장 시연 시나리오)

고객사 미팅이나 타사 제안 시 1분 만에 깊은 인상을 남길 수 있는 황금 시연 순서입니다.

1

[🎯 1클릭 샘플 데이터 로드] 클릭 (데이터 즉시 채우기)

소요: 1초

화면 우측 상단의 [🎯 1클릭 샘플 데이터 로드] 버튼을 누릅니다. 현대 스타리아(801부8744) 차량의 2026년 9월 한 달 치 70여 개 실제 방문지, 주차비, 주유비, 미운행일 데이터가 즉시 채워지며 달력과 통계 카드가 활성화됩니다.

2

회사명 클릭하여 '시연 대상 기업명'으로 맞춤 변경

소요: 2초

좌측 상단의 회사명 타이틀(예: (주)스마트물류 법인차량 운행관리 시스템)을 클릭하면 입력창이 뜹니다. 고객사 사명(예: (주)대한상사)을 입력하면 헤더와 출력 리포트에 해당 회사명으로 즉시 맞춤 브랜딩되어 몰입도를 극대화합니다.

3

[⚡ 월말 Km 자동분배] 시연 (실무자의 오랜 고통 해결)

핵심 와우 포인트!

[⚡ 월말 Km 자동분배] 버튼을 누르고, 당월 말 계기판 종료 숫자(예: 32,850)를 입력한 뒤 [마일리지 자동분배 및 저장]을 누릅니다. 복잡한 계산 없이 한 달 치 모든 방문지의 구간거리와 계기판 숫자가 단 0.1초 만에 오차 0km로 완벽하게 연속 배분되는 모습을 직접 보여줍니다.

4

[📥 실무 12열 상세 CSV] 다운로드 후 엑셀에서 확인

즉시 제출 가능

[📥 실무 12열 상세 CSV]를 클릭하여 내려받은 엑셀 파일을 엽니다. 1~3행 우측 블록 통계부터 12개 표준 컬럼(날짜, 운전자, 순번, 방문지, 상세 도로명 주소, 출발/도착 계기판, 구간거리, 주차비, 주유비, 비고)이 빈틈없이 완성되어 회계팀에 바로 제출 가능한 상태임을 확인시킵니다.

Chapter 3

상세 기능 조작 가이드 (Feature Walkthrough)

1 법인차량 마스터 등록 및 관리

상단의 [차량 등록/관리] 버튼을 눌러 기업이 보유한 여러 대의 법인 차량(스타리아, 카니발, 아반떼, 봉고 등)을 추가하거나 수정합니다.

• 필수 입력 항목:
  • 차량 번호: 예) 801부8744 (중복 불가 고유 키)
  • 차종: 예) 스타리아, 카니발 9인승 등
  • 최근 계기판 Km: 운행일지 시작의 기준이 되는 마일리지 (예: 32,000)
  • 기본 배정 기사: 일지 작성 시 자동 선택될 기본 운전자명 (예: 조경찬)

2 일자별 운행일지 작성 & Daum 도로명 주소 검색

목록의 특정 날짜 카드 우측 [수정] 또는 상단의 [➕ 운행일지 신규] 버튼을 눌러 운행 내역을 편집합니다.

미운행 (주말/공휴일) 원터치 토글

운행하지 않은 휴일이나 주말은 [미운행(미운행일) 체크]만 켜면, 시작/종료 Km가 동일하게 고정되고 운행자명이 '미운행'으로 자동 마킹되어 국세청 요건을 충족합니다.

[🔍 주소 검색] 도로명 자동완성

경유지 주소창 옆 [검색]을 누르면 카카오/Daum 우편번호 팝업이 뜹니다. 검색어(예: SJ테크노빌)를 누르면 표준 도로명 주소와 건물명이 1초 만에 자동 완성됩니다.

• 경유지 추가 및 비용 관리:

[+ 경유지 추가] 버튼으로 하루 최대 10곳 이상의 방문지를 자유롭게 등록할 수 있으며, 각 방문지별로 발생한 주차비 영수증 금액 및 주유비를 개별 기입할 수 있습니다.

3 월말 계기판 Km 스마트 자동분배 엔진

수십 개의 방문지를 돌면서 기사가 일일이 계기판을 기록하지 못하는 실무 현실을 완벽하게 해결합니다.

💡 스마트 자동분배 알고리즘 원리 오차 0.00km 보장
1. 총 주행거리 산출: 총 주행거리 = 월말 최종 계기판 - 월초 시작 계기판
2. 방문지 가중치 비례 배분: 당월 실제 운행한 전체 방문지 수(가중치)에 맞추어 구간거리 기본 분배.
3. 정수 반올림 및 100% 잔여 보정: 소수점 오차를 마지막 날짜에 정확히 가감 보정하여 최종 합계 일치.
4. 계기판 연속성 체인 형성: 전날 도착 계기판 = 다음날 출발 계기판으로 체결되어 역전율 0% 달성.

4 국세청 법정 양식 및 실무 12열 듀얼 엑셀 출력

버튼 클릭 즉시 엑셀(CSV) 파일로 변환되어 다운로드됩니다.

[📥 실무 12열 상세 CSV]

상단 1~3행 우측 통계 블록 + 12개 열 규격으로, 방문지별 도로명 주소와 출발/도착 계기판, 주차비, 주유비가 모두 분리되어 회계 정산에 가장 최적화되어 있습니다.

[📥 국세청 요약 CSV]

국세청 법인세법 시행규칙 별지 제29호 서식(업무용승용차 운행기록부)에 100% 부합하는 1일 1행 요약 법정 제출용 서식입니다.

Chapter 4

B2B 도입 FAQ & 데모 상담 질의응답 (Q&A)

Q1. 기업 내부의 차량 정보나 운행 주소가 외부 서버에 유출될 위험은 없나요?

답변: 전혀 없습니다. 본 솔루션은 100% 클라이언트 브라우저의 보안 격리 공간(`LocalStorage`)에만 데이터를 암호화 보관하며, 어떠한 외부 중앙 서버로도 운행 정보를 전송하지 않는 완벽한 독립 보안 아키텍처를 가집니다.

Q2. 인터넷이 불안정하거나 오프라인 환경에서도 작동하나요?

답변: 네, 정상 작동합니다. 초기 웹페이지 로드 이후에는 인터넷 연결 없이도 차량 등록, 일지 작성, 계기판 자동분배, 엑셀 CSV 다운로드 등 핵심 기능이 브라우저 내부에서 단독으로 완벽히 실행됩니다.

Q3. 우리 회사의 기존 엑셀 양식이나 ERP에 맞추어 커스터마이징이 가능한가요?

답변: 얼마든지 가능합니다. 가벼운 독립형 자바스크립트 구조로 설계되어 있어, 귀사의 특화된 엑셀 컬럼 서식, 부서별 차량 분류, 추가 비용 항목 등을 하루 만에 맞춤 커스터마이징하여 제공해 드릴 수 있습니다.

Q4. 컴퓨터를 바꾸거나 담당자가 바뀌었을 때 데이터를 어떻게 옮기나요?

답변: [백업/복원] 메뉴로 1초 만에 가능합니다. 상단의 [백업/복원] ➔ [백업 파일 다운로드]를 누르면 전체 운행 데이터가 JSON 단일 파일로 저장되며, 새 PC에서 [백업 파일 불러오기]를 누르면 100% 동일하게 복원됩니다.
