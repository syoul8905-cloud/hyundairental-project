1. 스마트폰 바탕화면에 배송차량 바로가기 추가 (필수)

매번 인터넷 주소를 입력하지 않고 앱처럼 1초 만에 실행하는 방법

최초 1회 바탕화면에 아이콘을 만들어 두시면 매일 출근 시 터치 한 번으로 열립니다!

스마트폰 브라우저로 접속 주소(https://hyundairental-project-1.vercel.app/mobile.html)를 연 후 아래 안내에 따라 설치하세요.

갤럭시 / 안드로이드 (Chrome)
  1. 화면 상단의 노란색 [🚚 바로가기] 버튼 또는 화면 안내 배너의 [설치] 터치
  2. 팝업창에서 파란색 [바탕화면에 배송차량 아이콘 추가하기] 터치
  3. 브라우저 설치 팝업이 뜨면 [설치] 또는 [추가] 선택
  4. 스마트폰 바탕화면에 배송차량 아이콘이 생성됩니다!
* 팝업이 안 뜰 경우: 크롬 우측 상단 [점 3개] ➔ [홈 화면에 추가] 터치
아이폰 (Safari 사파리)
  1. 사파리 브라우저 하단 중앙의 [공유 아이콘 ] 터치
  2. 메뉴를 아래로 스크롤하여 [홈 화면에 추가 ] 터치
  3. 우측 상단의 [추가] 글자 터치
  4. 아이폰 바탕화면에 배송차량 아이콘이 즉시 생성됩니다!
* 사파리(Safari) 브라우저에서 실행하셔야 홈 화면 추가가 지원됩니다.

2. 로그인 및 당일 배송 스케줄 자동 로드

본인 계정 로그인 및 배정 건 실시간 확인

기사 계정 로그인

최초 1회 관리자에게 부여받은 ID(예: 김승지)와 비밀번호를 입력하고 로그인합니다. 로그인 정보는 스마트폰에 안전하게 유지됩니다.

본인 배정 건 자동 선별

로그인 즉시 오늘 날짜 기준으로 본인에게 배정된 배송/회수 일정만 자동으로 선별되어 세로 카드 리스트로 정렬됩니다.

상단 실시간 진행률

화면 상단에서 [총 N건 중 완료 N건, 남은 배송 N건] 현황과 그라데이션 진행률 바를 실시간으로 확인합니다.

3. 현장 배송 업무 핵심 기능 (티맵 안내 & 도착 기록)

주소 검색 없이 원터치 길안내 실행 및 시간 자동 전송

티맵 길안내 ↗ 출발 시 필수 터치!

다음 배송지로 출발하기 전 이 버튼을 누릅니다.

  • • 스마트폰의 티맵(T-map) 앱이 즉시 실행되며 목적지 주소가 자동 입력되어 바로 길안내가 시작됩니다.
  • • 중요: 버튼을 누르는 순간 시스템에 [출발 시각]이 자동 기록되어 관리자에게 전송됩니다.
배송지 도착 🏁 현장 도착 시 터치!

고객사 현장에 차량을 대고 도착했을 때 이 버튼을 누릅니다.

  • • 배송 카드가 [도착 완료] 상태로 변경되며 상단 진행률이 올라갑니다.
  • • 중요: 버튼을 누르는 순간 시스템에 [도착 시각]이 자동 기록되어 관리자 대시보드에 즉시 표출됩니다.

4. 고객사 원터치 통화 및 영업 요청사항 확인

배송 전 통화 연결 및 관리자 전달 메모 확인

원터치 전화 걸기

고객사명 옆의 [📞 초록색 전화 아이콘]을 터치하면 담당자 번호가 스마트폰 다이얼에 자동 입력되어 즉시 통화로 연결됩니다. 번호를 외우거나 따로 입력할 필요가 전혀 없습니다.

비고 (영업 요청 / 관리자 지시)

배송 카드 하단에 노란색 메모 배너가 있을 경우 반드시 확인하세요. "도착 10분 전 사전 통화 필수", "후문 화물 엘리베이터 이용", "결제 단말기 지참" 등 중요한 현장 지시사항이 적혀 있습니다.

5. 현장 상황에 따른 방문 순서 변경

교통 정체나 고객사 사정으로 순서를 바꿔야 할 때

각 배송 카드의 우측에 있는 [▲ 위로] 및 [▼ 아래로] 버튼을 누르면 해당 배송지의 방문 순서를 자유롭게 바꿀 수 있습니다. 순서를 바꾸면 번호(1번, 2번...)가 즉시 재계산되며 스마트폰 화면에 즉각 반영됩니다.

6. [전체 지도 보기 & 실제 주행 경로 계산] 활용법

오늘 하루 나의 전체 배송지 위치와 실제 도로 내비게이션 주행선 확인

어디서나 원터치로 풀스크린 지도 팝업 실행

화면 하단 고정 바의 [🗺️ 지도 보기] 또는 상단 [전체 배송 지도 보기] 터치

1. 카카오맵 순번 마커 확인

지도가 열리면 오늘 가야 할 배송지들이 1번부터 끝 번호까지 파란색 원형 핀으로 지도 위에 한눈에 표시됩니다. 핀을 터치하면 고객사명과 주소가 인포윈도우로 나타납니다.

2. 실제 경로 계산 (교통상황 반영)

지도 상단의 보라색 [🚗 실제 경로 계산] 버튼을 누르면, 단순 직선이 아니라 실제 자동차 도로망을 따라가는 파란색 주행선이 그려집니다.

💡 실제 도로 주행거리 및 소요시간 배너 안내:

경로 계산 완료 시 상단 배너에 "총 주행거리: 45.2km · 예상 소요시간: 1시간 18분" 형태로 실제 이동 거리와 시간이 표출되므로 오늘 하루 전체 운행 일정을 사전에 계획하기에 매우 유용합니다.

7. 배송 기사 실무 꿀팁 및 FAQ

현장에서 자주 묻는 질문 및 대응 요령

Q. 티맵 버튼을 눌렀는데 티맵 앱이 안 열려요.

A. 스마트폰에 티맵(T-map) 앱이 설치되어 있는지 확인해주세요. 설치되어 있지 않다면 앱스토어/플레이스토어에서 티맵을 먼저 설치하시면 이후 원터치로 바로 연동됩니다.

Q. 관리자가 배송 건을 추가해주었는데 모바일 화면에 안 보여요.

A. 모바일 화면 우측 상단의 [새로고침 ] 아이콘을 터치하시면 최신 배송 스케줄이 0.5초 만에 즉시 갱신됩니다.

Q. 티맵 안내를 깜빡하고 누르지 않고 현장에 도착했어요.

A. 걱정하지 마시고 현장에서 [배송지 도착 🏁] 버튼을 바로 눌러주세요. 도착 시간은 정상 기록되며, 필요 시 관리자가 대시보드에서 보정할 수 있습니다.
