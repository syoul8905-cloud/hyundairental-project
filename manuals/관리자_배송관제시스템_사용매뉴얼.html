관리자(Admin) 전용 통합 운영 및 관제 업무 매뉴얼

현대렌탈서비스 배송물류운영팀 버전: 2.0 (단독 웹 / Supabase Cloud 연동) · 2026.09

시스템 개요 및 운영 목적

본 시스템은 현대렌탈의 배송 및 회수 일정을 실시간으로 관리·관제하는 단독 웹 클라우드 플랫폼입니다. 관리자는 ERP에서 추출된 일일 CSV 스케줄 파일을 1클릭으로 등록하고, 지도상에서 최적 배송 동선을 확인하며, 현장 배송기사별 스케줄 배정 및 출발·도착 시간 관제를 원스톱으로 수행할 수 있습니다.

관리자 웹 브라우저 접속 및 권한 로그인 안내

접속 URL 안내

  • • 로그인 성공 시 상단에 [최두성 (관리자)] 뱃지가 표출됩니다.
  • • 관리자 권한 로그인 시에만 CSV 등록 및 시간 관리 메뉴가 활성화됩니다.

3. 배송 스케줄 CSV 파일 일괄 등록

ERP 엑셀 원본 파일의 자동 필터링 및 클라우드 적재

스마트 CSV 파싱 및 자동 선별 엔진

ERP에서 내려받은 원본 CSV 파일을 드래그앤드롭하기만 하면, 시스템이 수작업 분류 없이 유효한 배송 건을 0.1초 만에 자동 선별합니다.

자동 등록 대상 (통과)

• 직배송 (direct): 차량 현장 배송 건

• 방문수령 (pickup): 고객 직접 수령 건

* 배송예정시간순으로 자동 정렬 장전

자동 제외 대상 (필터링)

• 택배 발송 건 (delivery)

• 전산/설치 대행 건 (install)

* 현장 차량 동선과 무관한 건 원천 배제

CSV 업로드 3단계 절차:

STEP 1
[CSV 등록] 클릭

상단 GNB 메뉴의 보라색 [CSV 등록] 버튼을 누릅니다.

STEP 2
배송일자 확인 & 파일 드롭

스케줄을 넣을 배송일자를 확인하고 CSV 파일을 영역에 드래그합니다.

STEP 3
선별 결과 확인 & 적재

통과 건수(직배송/방문수령)를 확인하고 [DB 일괄 적재]를 클릭합니다.

4. 배송 현황 관제 및 담당기사 배정

마스터 테이블 기반 인라인 수정 및 다중 일괄 배정 기능

1클릭 다중 일괄 배정 (Batch Assign)

테이블 좌측의 체크박스로 원하는 배송 건들을 다중 선택하면, 상단에 플로팅 일괄 배정 툴바가 자동으로 나타납니다. 담당기사를 선택하고 [일괄 배정]을 누르면 수십 건도 1초 만에 클라우드에 일괄 저장됩니다.

테이블 인라인 개별 배정

테이블 각 행의 [담당기사] 셀렉트 박스를 클릭하여 원하는 기사로 변경하면 별도의 저장 버튼 없이 즉시 Supabase DB에 반영됩니다.

'비고(영업 요청 / 관리자 지시)' 실시간 인라인 작성

테이블의 [비고] 컬럼에 "결제기 지참 요망", "도착 전 통화 필수" 등 지시사항을 입력하고 엔터 또는 포커스 아웃 시 즉시 저장되며, 배송기사 스마트폰 모바일 웹 카드에도 노란색 메모 배너로 실시간 전달됩니다.

5. 카카오맵 동선 관제 및 배송 순서 최적화

고해상도 전자지도 경로 관제 및 드래그앤드롭 방문 순서 조정

카카오맵 경로 관제 기능

  • • 순번 마커 핀: 1번부터 N번까지 배송 순서 번호가 지도 위에 직관적으로 표출됩니다.
  • • 마커 클릭 상세 정보: 고객사명, 주소, 연락처, 품목 정보 인포윈도우 확인.
  • • 출발지 설정 (🏢 가산 센터 vs 🏠 기사 자택): 헤더 드롭다운에서 출발지를 선택하거나 직접 주소를 수정 저장 가능.
  • • 기사별 전용 동선 필터링: 특정 기사 선택 시 해당 기사의 배송지만 지도에 깔끔하게 표출.

배송 순서 커스텀 조정

  • • 마우스 드래그 앤 드롭: 좌측 타임라인 카드를 마우스로 끌어서 순서를 즉시 맞바꿀 수 있습니다.
  • • ▲ / ▼ 버튼: 터치 또는 1클릭으로 한 단계씩 위/아래로 이동 가능.
  • • [시간순 복원] 버튼: 순서가 꼬였을 때 원클릭으로 초기 배송시간 오름차순으로 즉시 복원.
  • • 순서 변경 시 지도 상의 마커 번호가 0.05초 만에 실시간 재정렬됩니다.

6. 배송 스케줄 시간 관리 (관리자 전용 대시보드)

배송기사의 티맵 출발 및 현장 도착 시간 실시간 추적

배송 스케줄 시간 관리 진입 방법 관리자 전용 새 창

화면 우측 상단 [사용자 메뉴] ➔ [배송 스케줄 시간 관리]를 클릭하면 독립된 대시보드 창이 오픈됩니다.

1. 실시간 타임스탬프

기사가 티맵을 켠 순간(출발)과 현장 도착을 누른 순간(도착)이 초 단위로 자동 기록됩니다.

2. 구간 소요시간 자동 계산

출발~도착 간 이동 소요 시간(분)이 자동으로 산출되어 배송 지연 여부를 즉시 파악합니다.

3. 엑셀/CSV 데이터 내보내기

기록된 배송 시간 일지를 1클릭으로 엑셀 파일로 내려받아 월간 물류 리포트에 활용합니다.

7. 모바일 관리자 관제 (외근·이동 중 스마트폰 관제)

현장 외근 중 스마트폰 화면에 최적화된 모바일 전용 카드 뷰

적응형 2-View 스위처 탑재

스마트폰으로 관제 시스템에 접속하면 자동으로 화면 상단에 [🗺️ 지도 & 동선] ↔ [📋 배송목록 & 기사배정] 탭이 제공됩니다. 모바일 카드 뷰 내에서 체크박스 일괄 배정, 기사 변경, 비고 작성이 100% 터치로 원활하게 작동합니다.
